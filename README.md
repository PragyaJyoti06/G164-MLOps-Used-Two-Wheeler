## Project Objective

The objective of this project is to develop an end-to-end MLOps pipeline that predicts the resale price of used two-wheelers in Guwahati using machine learning.

The project includes data versioning, data cleaning, model training, experiment tracking, model registration, API development, containerization, automated testing, Kubernetes configuration, monitoring and model retraining.

## Target Variable

`resale_thousand_rs`

## Evaluation Metric

Mean Absolute Error (MAE)
